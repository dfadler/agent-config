# storybook plugin for Claude Code

One skill for agents that write, run or verify Storybook stories. Claims link to the
Storybook docs.

| Piece | Use |
|-------|-----|
| `storybook:storybook-usage` | Writing or editing a `*.stories.*` file; starting or building Storybook; running play-function tests; confirming a story renders |

Recording a play function as video belongs to the `playwright` plugin; screenshots belong to
`screen-capture`.
