`evals/standup-blocked-detection/case.yaml`
```yaml
schema_version: "1.1"
name: standup-blocked-detection
# Target sentence: "Blocked: anything the commits say is waiting on someone else, or "Nothing"."
# good-reply: Blocked line names the wait on the design team's API spec. A second reply with no waiting commits says "Blocked: Nothing".
# bad-reply: Blocked line says Nothing despite a commit saying it is waiting on someone, or invents a blocker.
prompt: |
  Here's my git log from yesterday, write the standup:
  9f8e7d XYZ-45 stub export endpoint, waiting on design team for API spec
  3c2b1a XYZ-45 add export unit tests
graders:
  - type: regex
    pattern: '(?i)Blocked:.*(design|spec)'
  - type: regex
    # FAIL if Blocked says Nothing
    pattern: '(?i)Blocked:\s*(?!Nothing)'
```
